## Needs

A few hundred thousand quiet positions with known game outcomes, generated by
self-play, and a tuner. Worth more than several S027 terms put together: it is
what turns a set of plausible numbers into a tuned evaluation. Hand-picked
weights are the wrong weights, including the ones written by hand in S010 --
which are hand-written precisely because the published tuned ones were refused
(DEC-002).

## Split of work

The agent builds the tuner, generates and prepares the self-play data, and
states exactly what the run should be: inputs, objective, hyperparameters,
expected duration. **The owner executes the fit.** The constants come back and
are then measured by SPRT like any other change. DEC-015.
